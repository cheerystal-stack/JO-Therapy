# JO-Therapy v3

J-OSLER support PWA prototype.

## v3
- 7期生以降の120症例基準
- 56疾患群の自動カウント
- 領域別最低症例数・最低疾患群数の自動表示
- 領域選択に連動した疾患群選択
- 入院/外来・プログラム内外の補助カウント
- 症例一覧・編集・削除
- 旧自由入力データは「旧入力」と表示し、正式疾患群カウントから除外

## Source handling
- 修了要件: 2024年改定第2版（専攻医7期生以降）
- 疾患群構成: 2015年版 日本内科学会「研修手帳（疾患群項目表）」
- 疾患群の表示名はアプリ内識別用に一部簡略化
