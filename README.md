# JO-Therapy v3

J-OSLER support PWA prototype.

## v3
- 7期生以降の120症例基準
- 56疾患群の自動カウント
- 領域別最低症例数・最低疾患群数の自動表示
- 領域選択に連動した疾患群選択
- 入院/外来・プログラム内外の補助カウント
- 症例一覧・編集・削除
- 旧自由入力データは「旧入力」と表示し、正式疾患群カウントから除外

## Source handling
- 修了要件: 2024年改定第2版（専攻医7期生以降）
- 疾患群構成: 2015年版 日本内科学会「研修手帳（疾患群項目表）」
- 疾患群の表示名はアプリ内識別用に一部簡略化

## v4
- 病歴要約ワークスペース追加
- 症例ごとに匿名化カルテ原文をlocalStorage保存
- ①病歴 ②現症 ③検査 ④Problem/処方 ⑤経過・考察 ⑥総合考察 の6セクション
- 各セクションに「AI用プロンプトをコピー」
- 生成下書きの保存・コピー
- 保存済み下書きの一括コピー
- プロンプトは「不足を補わない」「未確認は要確認」「架空文献を作らない」を共通原則とする

※ v4は外部AI APIを接続していません。AI生成そのものではなく、ChatGPT等へ渡す安全な指示文を即時生成する段階です。

## v5
- 症例一覧に「要約作成」ボタンを追加
- 病歴要約ワークスペースに生成前チェック（PRE-FLIGHT）を追加
- 病歴・現症・検査・治療・治療反応・診断/治療根拠・退院時処方・全人的情報・自己省察材料の抜け候補を表示
- 個人識別情報キーワードの簡易警告
- セクションごとの下書き保存状態表示

重要：
- PRE-FLIGHTは公式J-OSLERの合否判定ではありません。
- 単純なルールベースの補助チェックであり、カルテ原文と公式手引きによる人間の確認が前提です。
