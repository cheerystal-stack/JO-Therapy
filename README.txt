JO-Therapy v6.2.1
FULLプロンプト調整版

変更点
- SECTION 05「入院後経過と考察」
  ・プロブレムごとの機械的な分割を抑制
  ・関連する問題は一つの症例ストーリーとして統合
  ・独立して記載した方が読みやすい場合のみ分割
  ・原文にない因果関係を接続詞で補わないルールを追加

- SECTION 06「総合考察」
  ・未確認事項や原文から断定できない点を本文に混ぜない
  ・必要に応じて【要確認】【注】へ分離
  ・未確認文献は［文献要確認］として明示
  ・原文にない因果関係を補わないルールを追加

互換性
- localStorageの既存キーは変更していません
- CASE BANK / QUICK / FULLの既存保存データを維持します
- data.js / manifest.json / icons は従来ファイルをそのまま使用します
