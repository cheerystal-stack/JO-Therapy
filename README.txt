JO-Therapy v6.2
FULLプロンプト刷新版

変更点
- SECTION 05「入院後経過と考察」を刷新
  ・所見 → 判断 → 対応 → 反応 → 次の判断 → 転帰 を重視
  ・鑑別、重症度、治療変更理由、併存疾患との関連を症例に応じて整理
  ・複数Problemは必要に応じて #1 / #2 で整理
- SECTION 06「総合考察」を刷新
  ・一般論だけで終わらず、必ず症例固有の所見・判断へ戻す
  ・重症度、診断、治療妥当性、副病名との関連、再発予防、学びを必要に応じて統合
  ・全人的視点は症例に関係する場合のみ反映
- PRE-FLIGHT「全人的情報」を必須扱いにしない文言へ調整
- キャッシュを v6.2 に更新

互換性
- localStorageの既存キーは変更していません
- CASE BANK / QUICK / FULLの既存保存データを維持します
- data.js / manifest.json / icons は従来ファイルをそのまま使用します

更新方法
GitHub上で以下4ファイルを置き換えてください。
- index.html
- app.js
- sw.js
- README.txt

style.cssは内容変更なしですが、同梱しています。
